# Prompts

- **`parti_sample.json`**: 48 prompts sampled from PartiPrompts (Apache-2.0, github.com/google-research/parti).
  - Sampled by `scripts/make_prompts.py`: seed 2027, 5 prompts from each of 10 categories, interleaved.
  - The People and World Knowledge categories are excluded, so the study never renders real persons.
- **`PartiPrompts.tsv`**: not committed. Download it from the PartiPrompts repository to re-run the sampling.
